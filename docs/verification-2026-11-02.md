# Проверки taskMaster — 2 ноября 2026

Среда: нативная Windows, самостоятельная debug-сборка Tauri, без установщика.
Релиз, установка и обновление не выполнялись по запросу пользователя.

## Проверено вручную

- Настройки показывают версию `0.1.0`, состояние уведомлений и автозапуска, сведения о локальных журналах.
- В пользовательской папке `logs` после запуска появилась корректная JSONL-запись `app_started` без содержимого задач.
- Диалог «Удалить навсегда» показывает название, предупреждение и количество событий; Escape закрывает диалог, задача остаётся в истории. Фактическое удаление пользовательских задач не выполнялось.
- Глобальная клавиша `Ctrl+Alt+Space` показывает и скрывает оверлей. Закрепление включается и выключается; исходное выключенное состояние восстановлено.
- Закрытие главного окна не завершает процесс. Повторный запуск показывает существующее окно; второй постоянный процесс не создаётся.
- Тестовая отправка уведомления завершается сообщением «Тестовое уведомление отправлено». Это проверка вызова API, а не подтверждение баннера и перехода по клику.
- Регистрация автозапуска текущего пользователя указывает на исполняемый файл в кавычках. Текущий включённый автозапуск не изменялся.

## Автоматические проверки

- `cargo test --locked --manifest-path src-tauri/Cargo.toml`: временные SQLite-базы; удаление/отмена/подтверждение, транзакционный откат, миграции, архив, напоминания, таймеры и резервные копии.
- Новый регрессионный тест проверяет архивацию в фоновом цикле до обработки напоминания, точную границу срока и отсутствие повторного архивного события.
- Три теста журналирования проверяют JSONL-формат, размер/ротацию, сохранность посторонних файлов и ошибку записи.
- `cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`.
- `cargo fmt --manifest-path src-tauri/Cargo.toml -- --check`.
- `npm test`, `npm run build`, `git diff --check`.

## Ограничения проверки

- Уведомления установленного приложения (имя, иконка, клик по задаче) требуют установленной сборки; debug использует отправителя Windows PowerShell.
- Фактический вход в Windows после перезагрузки, сон/пробуждение, смена системного DPI и физическое отключение монитора не выполнялись. Автоматические тесты восстановления таймеров, пропущенных напоминаний и ограничения позиции оверлея не заменяют эти проверки.
- Новые пункты трея скомпилированы в Windows, но выбор из системного меню вручную пока не проверен.

Проверки узкого окна и производительности фиксируются отдельно после этой итерации.
