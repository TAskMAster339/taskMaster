# Полный сброс — проверка 2026-11-03

## Поведение

«Очистить задачи» сохраняет таймеры, настройки и бэкапы. «Сбросить данные» отключает автозапуск, атомарно записывает запрос сброса и запрашивает перезапуск. До открытия SQLite, диагностического журнала и обоих WebView очищаются собственные папки roaming/local/cache приложения. Удаляются старые SQLite/WAL/SHM, встроенные и защитные бэкапы, журналы, JSON-настройки, localStorage и кэш WebView. Новый запуск создаёт только пустую базу и служебные данные по умолчанию; ежедневный бэкап в этом запуске пропускается. Файлы, экспортированные за пределы папок приложения, не затрагиваются.

Маркер остаётся до успешного завершения всех удалений; прерванная очистка повторяется при следующем запуске. Каталоги проверяются по идентификатору приложения и абсолютному разрешённому пути, ссылки/junction не обходятся. При неудаче не открывается частично очищенная база; нативное сообщение об ошибке показывается неблокирующим API, после его закрытия процесс завершается. Рабочие данные не сбрасывались при разработке.

## Red–Green

- Тест настроек SQLite сначала упал: вместо стандартных 15 минут сохранялось пользовательское значение 30.
- Четыре новых теста файлового сброса сначала упали на заглушке; после реализации прошли.
- Проверены все собственные папки, встроенные и защитные копии, профиль WebView, внешний экспорт, одинаковые local/cache пути, отсутствие и неверный маркер, отказ для чужого корня, повторный запуск и свежие настройки пустого приложения.
- На нативной Windows проверена блокировка SQLite-файла: незавершённый сброс сохраняет маркер и исходный файл, после освобождения дескриптора повторная очистка проходит.

## Границы проверки

Нативное окно приложения после изменения порядка инициализации запускается в dev-режиме Windows. Удаление проверено на временных папках и реальных Windows-дескрипторах. Полный пользовательский цикл нажатия кнопки, отключения регистрации автозапуска и перезапуска установленной сборки с настоящим профилем WebView не выполнялся: рабочие данные и регистрацию Windows не меняли. Браузерный тест имитирует запрос перезапуска, а не выполняет удаление пользовательских данных. Release-сборка и публикация не выполнялись.
