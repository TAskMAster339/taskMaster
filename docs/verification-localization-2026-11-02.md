# Проверка очистки, ссылок и локализации — 2026-11-02

## Автоматические проверки

- `npm test`: 8 тестов успешно (сочетания, порционная отрисовка, языки, полнота словарей, параметры ошибок).
- `npm run build`: TypeScript и production-сборка Vite успешно. Release-сборка Rust не запускалась.
- `cargo test --locked --manifest-path src-tauri/Cargo.toml --quiet`: 66 успешно, 1 ignored (benchmark).
- `cargo fmt --manifest-path src-tauri/Cargo.toml --check` и `cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`: успешно.
- Очистка: тесты сначала падали на сохранении данных вместо удаления и отсутствии rollback. Проверены оба режима, повторная очистка, сохранение настроек, неизменность файла бэкапа, восстановление и rollback при SQL-ошибке. Временные SQLite-базы; пользовательская база не очищалась.
- Ссылки: наблюдался падающий тест отсутствия allowlist, затем проверены два точных URL и отказ для остальных.
- Настройки отображения: наблюдались падающие тесты отсутствия сохранения/ошибок записи. Проверены японский по умолчанию, сохранение, чтение, неверный язык, повреждение и сохранность исходного файла при ошибке записи.

## Браузерные интеграционные проверки

Тесты используют настоящий frontend с Tauri mocks, исключительно искусственные данные и отдельные headless-контексты Microsoft Edge. Не подтверждают Windows toast delivery или озвучивание Narrator.

При работающем Vite: `node --test scripts/features.test.mjs`. Нужны `playwright` и `@axe-core/playwright`; в этом прогоне они установлены во временный каталог вне репозитория. Переменная `TASKMASTER_BROWSER_MODULES` указывает на этот каталог с `node_modules`; `TASKMASTER_DEV_URL` по умолчанию `http://127.0.0.1:1420`.

4 сценария прошли:

1. Японский при первом запуске, смена трёх языков, сохранение после reload, отсутствие русских строк в японском/английском экране настроек (кроме самоназвания Русский), сохранность пользовательского названия «Настройки», локализованная ошибка сохранения без ложного переключения.
2. Смена языка/контраста в другом окне, включая уже отображённые кнопки таймера оверлея.
3. Контраст обеих тем, forced-colors, три языка при 360×480 и масштабировании 200% при 920×700, отсутствие горизонтального переполнения.
4. Axe без нарушений на основных экранах и диалогах; постоянный status region, фокус запуска/паузы, отсутствие ежесекундного озвучивания статуса, возврат фокуса после Escape, фокус отмены очистки, обе ссылки вызывают ограниченную команду.

Визуально осмотрены скриншоты японских настроек при ширине 360px и английских настроек с высоким контрастом. Исправлены некорректные ARIA-роли форм горячих клавиш и наследование цвета в контрастном режиме.

## Ограничения ручной проверки

- Нативный Tauri dev запускается на Windows. Проверка дерева доступности выполнена через Windows UI Automation.
- Открытие двух ссылок из нативного окна в браузере не подтверждено; allowlist и вызовы frontend проверены автоматически.
- Реальное прослушивание через Windows Narrator, переключение контрастной темы в настройках Windows, установленная сборка и доставка уведомлений с её идентичностью не проверены. Forced-colors проверен через эмуляцию Edge.
- Реальные пользовательские данные и автозапуск в ходе проверок не удалялись и не сбрасывались.
