# Дизайн taskMaster

Этот документ фиксирует визуальную систему главного окна taskMaster. При изменении интерфейса сначала используй эти правила и токены; новые визуальные решения добавляй сюда вместе с их реализацией.

## Направление

- Минималистичный рабочий список, в котором первыми читаются название и номер задачи.
- Спокойный тёмный графитовый фон, тёплая светлая тема и один лаймовый акцент.
- Чёткая типографика, тонкие разделители, небольшое число поверхностей и минимум декоративных подписей.
- Без мотивационных слоганов и повторения информации, уже показанной счётчиком или действием.

## Типографика

- Основной шрифт: Segoe UI с системным sans-serif запасным вариантом.
- Заголовок страницы: 32–40 px, плотное начертание; дата и названия разделов — мелкие, но контрастные.
- Название задачи: 13 px и межстрочный интервал около 1.5; длинный текст переносится внутри строки.
- Номер активной задачи: 14 px, полужирный, табличные цифры, выравнивание по центру.
- Номер выполненной задачи показывается тем же размером и выравниванием, что номер активной задачи.
- Чекбокс активной задачи: 22 × 22 px. Номер и чекбокс выровнены по центру строки, в том числе при многострочном названии.

## Список и состояния задач

- Активная очередь — главный список. Номера соответствуют ручному порядку.
- Выполненные задачи остаются читаемыми: без зачёркивания и с цветом `--completed-ink`.
- Чекбокс в покое — прозрачная поверхность с контрастной рамкой. Отмеченный чекбокс — лаймовая заливка с тёмной галочкой; не используй чёрную заливку.
- При наведении и перетаскивании применяй тот же акцент, не меняя цвет текста так, чтобы он терял контраст.
- Скроллбар появляется только при переполнении, его бегунок использует `--accent`.

## Темы

- По умолчанию выбран режим «Система», который следует системной теме Windows.
- Режимы «Светлая» и «Тёмная» используют один набор семантических токенов с отдельными значениями из таблицы выше.
- Проверяй обе темы при изменении компонентов. В светлой теме не используй чисто чёрные активные плашки, бледный текст или лаймовый текст на светлом фоне.
- Цвет выделения текста, фокуса и отметки задачи должен соответствовать акцентным токенам.

## Движение

- Завершение задачи: чекбокс, временное зачёркивание, затем сжатие строки; вся последовательность длится примерно 2 секунды.
- Во время перехода выполнения или возврата блокируются только действия со строкой этой задачи; анимации разных задач могут идти параллельно.
- Во время анимаций навигация между вкладками остаётся доступной.
- Возврат из выполненных анимирует снятие отметки и уход строки из списка.
- После завершения название остаётся обычным, незачёркнутым текстом на вкладке «Выполнено».
- Изменение порядка плавно прокручивает номера к новым значениям.
- Новая задача появляется в конце очереди; строка мягко проявляется, название раскрывается слева направо.
- Учитывай `prefers-reduced-motion`: при включённом системном параметре анимации должны быть практически мгновенными.

## Компоновка и копирайт

- Боковая панель содержит навигацию и переключение темы внизу.
- Логотип не дублируется внутри интерфейса. Бренд приложения отображается только в системной рамке окна и значке на панели задач Windows.
- При ширине окна до 680 px навигация перемещается в верхнюю панель; вкладки центрируются по доступному пространству и прокручиваются при переполнении.
- Название режима темы отображается без слова «Тема»; системный режим подписан «Системная».
- Ширина переключателя темы фиксирована в компактной панели, чтобы смена названия не сдвигала навигацию. Навигация центрируется, пока помещается, и прокручивается по горизонтали при добавлении вкладок.
- Страница «Сегодня» содержит дату, счётчик, быстрое добавление и очередь. Страница «Выполнено» использует ту же структуру без поля создания.
- Сохраняй внутренние отступы, работу на ширине от 360 px и прокрутку длинных списков внутри их области.
- Текст интерфейса короткий и буквальный: только действие, состояние, ошибка или доступное имя.
