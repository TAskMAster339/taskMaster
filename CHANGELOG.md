# Changelog

Все заметные изменения проекта фиксируются здесь. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Добавлено

- Добавлена последовательная анимация выполнения задачи и появления новой задачи в конце очереди с раскрытием названия слева направо.
- Обновлено оформление экрана «Сегодня» в строгом типографическом стиле с лаймовым акцентом.
- Добавлено переключение тем: системная, тёмная и светлая; выбор сохраняется между запусками.
- Добавлена вкладка «Выполнено» со списком задач, отмеченных сегодня, и возвратом задачи в очередь.

### Изменено

- Номера задач плавно прокручиваются к новым значениям при завершении и перестановке; анимации учитывают системное уменьшение движения.
- Скроллбар списка оформлен акцентным цветом; выделение текста и подсветка перетаскивания используют тот же акцент.
- Счётчик задач смещён от правого края и центрирован; из выполненных строк убрана подпись «Готово».
- Очередь с большим числом или длинными названиями прокручивается внутри своей области; во время перетаскивания список прокручивается у краёв.
- Выполненные задачи перенесены из нижнего блока в отдельную вкладку; чекбокс возвращает выбранную задачу в конец очереди.
- Удалены дублирующие счётчики и поясняющие подписи с экрана «Сегодня».
- Увеличены внутренние отступы, номер задачи перенесён перед чекбоксом, убраны футер, локальная подпись и лишний значок у поля ввода.
- Перестановка левой кнопкой мыши подсвечивает строку назначения и сохраняет новый порядок с обновлёнными номерами; перемещение с клавиатуры сохранено.
- Перетаскиваемая задача следует за курсором; из строк убраны дополнительные кнопки, переименование доступно двойным щелчком или клавишей F2.
- Добавлены CI workflow для проверок Rust и frontend и ручная публикация Windows release в GitHub Releases.
- Добавлен PowerShell-сценарий для сборки и запуска taskMaster.
- Создан desktop MVP: локальная очередь задач с редактированием, завершением, восстановлением и ручной перестановкой.
